E-Scooter Parking Suitability in Eugene

The purpose of this project was to determine the the most suitible locations to place E-scooter ride-share hubs in Eugene, Oregon. Using three suitability sub-models (Eugene zoning, population density, and exsiting bike friendly street networks) it was possible to construct a weighted raster overlay. This approach makes it possible to take multiple variables into account while selecting E-scooter hub locations.

Suitability Map

The map on the left represents the final product of this project. Here, the zones with the high placement suitability scores are represented in green and the zones with the low scores are represented in red. The map on the right represents each of sub-models used to calculate placement suitability.


Lost Hiker Search Areas

The goal for this project was to create a set a of maps that could serve as reference material for a search and rescue team. In this scenario, a hiker went missing while trekking toward Camelot Lake. Using elevation data, road and trail networks, and land cover information, it is possible to suggest where a rescue team should start within the search area.

Search Area Base Map

This map gives a sense of the search area before running any intesive analysis. It shows the hiker's starting postion and goal location (Camelot Lake), as well as nearby road and trail networks and waterbodies. This is all information that can contribute to future search suggestions.

Lost Hiker Search Suggestions

This map displays the final search suggestions for the lost hiker. here you can see the most optimimal path from the start and goal point in red. Along this path you ca see all of the intersecting roads and trails in orange in green, as well as nearby waterbodies in blue. While this map is in no way an extensive guide to possible lost hiker locations, it could potentially serve as a good set of starting points, backed up by spatial data.
